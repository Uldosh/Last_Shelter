# Student Checklist

## Repository

- [ ] Source code is committed.
- [ ] Gradle wrapper files are present.
- [ ] Documentation files are present: `README.md`, `ASSIGNMENT.md`, `FAQ.md`, and `STUDENT_CHECKLIST.md`.
- [ ] `.gitignore` excludes generated build output and local IDE files.

## Build And Run

- [ ] `gradlew.bat desktop:run` launches the game.
- [ ] `gradlew.bat desktop:classes` compiles the project.
- [ ] `build.bat` creates `desktop/build/libs/LAST_SHELTER.jar`.
- [ ] `export_exe.bat` creates `dist/LAST_SHELTER.exe` when Launch4j is configured.

## Gameplay

- [ ] First-person camera, mouse look, WASD movement, sprint, collision, and pause work.
- [ ] Main Hall, Generator Room, Water Sector, AI Core Room, and Storage Room are reachable.
- [ ] Interactions use world objects and the `E` key.
- [ ] Mini-games return to 3D gameplay after success or failure.
- [ ] Daily objectives, survival resources, AI monitor messages, and ending/game-over screens are visible.
- [ ] Save/load, autosave, checkpoints, settings, and fullscreen toggle work.

## Team Notes

- [ ] Student responsibilities in the README match the project work.
- [ ] The repository history is ready to share on GitHub.
